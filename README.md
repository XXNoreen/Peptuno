# Peptuno

A personal peptide protocol planner, injection calendar, vial tracker and weight log. Set up a protocol once — vial, start date, cycle, frequency, time and dose steps — and Peptuno builds the schedule, calendar, vial usage and "vial empty" estimates for you. Works on phones, tablets and computers, and can be installed like an app.

**Live app:** https://xxnoreen.github.io/Peptuno/

> Peptuno is a tracking and calculation tool, not a medical or prescribing tool. It doesn't recommend doses or dose changes.

## Turn on the live app (one time)

1. Upload every file and folder in this package to the repo (see below).
2. In the repo, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, **Branch** to **main**, folder **/ (root)**, then **Save**.
4. After about a minute, open https://xxnoreen.github.io/Peptuno/

## Uploading files

On https://github.com/XXNoreen/Peptuno click **Add file → Upload files** (or **uploading an existing file** if the repo is empty), drag in everything from this folder — including the `brand` folder — and click **Commit changes**.

`.nojekyll` starts with a dot, so your computer may hide it. It's optional.

## Install on your devices

- **iPhone / iPad:** open the link in Safari → Share → **Add to Home Screen**.
- **Android:** open in Chrome → ⋮ → **Install app**.
- **Windows / Mac:** open in Chrome or Edge → click the install icon in the address bar (or ⋮ → **Install Peptuno**).

Installed Peptuno opens full screen, has its own icon, and works offline.

## Your data

This version has no server and no sign-in. Everything stays in the browser on each device; nothing is uploaded. Use **Menu → Export my data** to back up, and **Profile → Import data** to move it to another device.

## Sharing protocols

On any protocol, tap **Export / share CSV**. Others import it in **My Stack → Import protocol**, check the pre-filled steps and pick their own start date. To write one from scratch, fill in `peptuno-protocol-template.csv`.

## Updating the app

Upload the new `index.html` (and any other changed files) with **Add file → Upload files → Commit changes**. The site updates in about a minute, and installed apps pick up the new version the next time they open online. Every change is kept in the repo history, so you can roll back any time.

## Brand files

`brand/` has the logo (light and dark versions) as SVG and PNG, plus the app mark.
